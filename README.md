
# O Level Computer Science - Paper 2 Scenario Questions (Python)

A comprehensive collection of O Level Computer Science (2210) Paper 2 scenario-based programming questions with solutions in Python.

## 📚 About This Repository

This repository contains practical scenario questions from the Cambridge O Level Computer Science syllabus, specifically focused on **Paper 2 (Programming and Problem Solving)**. Each question includes:

- Problem statement and requirements
- Sample test cases
- Complete Python solution
- Explanation of approach and key concepts
- Alternative solutions (where applicable)

## 📋 Contents

The repository is organized by topic/skill area:

- **Data Structures** — Lists, dictionaries, tuples, sets
- **File Handling** — Reading/writing files, data processing
- **Functions & Modular Programming** — Function design, parameters, return values
- **Algorithm Design** — Sorting, searching, pattern matching
- **String Manipulation** — Text processing and validation
- **Problem Solving** — Complex multi-step scenarios
